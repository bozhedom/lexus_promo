# Промо-воронка «Персональный пригласительный»

Next.js 16 + Payload CMS. Посетитель вводит госномер, машина определяется по
внешнему API, дальше он оставляет имя и телефон и получает пригласительный
с подарком, который можно сохранить картинкой.

## Запуск

Нужны Node 20+ и Docker.

```bash
cp .env.example .env
```

В `.env` заполните `PAYLOAD_SECRET` (`openssl rand -hex 32`). Остальное для
локальной работы уже проставлено.

```bash
npm install
npm run db:up
npm run migrate
npm run dev
```

Сайт — http://localhost:3000, админка — http://localhost:3000/admin.
Аккаунт заводится командой `npm run admin:reset` по данным из `.env`
(см. «Доступ в админку»).

Три варианта QR-ссылок для первого экрана:

- `/?toyota` — только Toyota;
- `/?lexus` — только Lexus;
- `/` — Toyota и Lexus вместе.

С первого экрана расходятся две ветки. «Получить приглашение» ведёт за
пригласительным: `/car-number` → `/car-info` → `/personal`. «Рассчитать и
записаться» — на запись в сервис: `/booking/car-number` →
`/booking/car-info` → `/booking/appointment`. Экраны номера и автомобиля общие,
ветку им передаёт страница (`flow`), а маршруты лежат в
`src/shared/lib/flow.ts`. Выданные пригласительные ветку записи не
перехватывают: гость, которому их уже выписали, проходит определение
автомобиля так же, как все.

На записи пригласительные не выписываются. Карточка автомобиля показывается
всегда — и когда его определили по номеру, и когда гость вписал марку руками, —
а вместо подарков на ней три работы с чекбоксами (список лежит в
`src/shared/config/services.ts`). «Это мой автомобиль» уводит на
`/booking/appointment`, где сразу стоят три кнопки мессенджеров: гость выбирает
любую и уходит в чат с готовым текстом про свой автомобиль и отмеченные работы.
Макета у этого экрана пока нет — свёрстан он теми же карточкой и рядом кнопок,
что и остальные окна воронки.

Раздел «Тексты сообщений» держит формулировки, которые уходят в мессенджеры:
сообщение, приходящее гостю вместе с пригласительными, текст, который гость
отправляет менеджеру, и текст записи на сервис. Подстановки пишутся в фигурных
скобках — `{name}`, `{car}`, `{plate}`, `{amount}`, `{code}`, `{services}`;
строка, где все подстановки оказались пустыми, из сообщения выпадает целиком.
Если в тексте записи нет `{services}`, отмеченные работы дописываются отдельной
строкой в конце — так их не потеряет уже настроенная формулировка. Правка
применяется к следующей выдаче, перезапускать приложение не нужно, а пустое
поле возвращает текст по умолчанию из
`src/invite-test/config/certificates.ts`. Убирать `{code}` из текста гостя
нельзя: по нему сервер понимает, кому отправлять пригласительные.

В админке раздел «Слайды автоцентра» управляет фотографиями под формой и их
вертикальными версиями для мобильного полноэкранного просмотра. Раздел
«Правила сумм» задаёт сумму сертификата для списков моделей; при отсутствии
подходящего правила используется `CERT_AMOUNT`, затем значение 1500 ₽.

Раздел «Марки и модели» управляет каталогом ручного ввода. По умолчанию в нём
доступны только Toyota и Lexus; опубликованные дополнительные марки и модели
автоматически появляются в форме.

Раздел «Фото автомобилей» — кадры, на которых печатается пригласительный, и
единственный источник этих кадров. Весь каталог живёт здесь: тридцать один
кадр приезжает миграцией `20260813_190000_car_photos_seed`, дальше фотография
меняется загрузкой файла, рамка знака — процентами, а новая модель заводится
кнопкой. Где база поднята схемой разработки и до миграций дело не доходит,
раздел заполняет `npm run seed:car-photos`; повторный запуск непустой раздел не
трогает.

Кадр подбирается по марке, модели и году: чем точнее совпадение, тем выше
приоритет. Пустая модель означает «любая модель этой марки», пустые годы —
«любой год». Загружать нужно вертикальный кадр не меньше 1080×1920: под
госномер на нём должно остаться пустое место, а куда именно печатать номер,
задают проценты в блоке «Рамка госномера».

Поколения одной модели разводятся годом выпуска: у нового кадра годов нет,
поэтому он же достаётся автомобилю с неизвестным годом, а старому проставлен
верхний год. В каталоге модель называется без поколения («RAV4», «LX»),
и по-другому их не различить.

Те же кадры лежат в `public/images/cert/cars`, а список — в
`src/shared/config/car-photos.ts`. Это страховка: встроенный список
подставляется, только когда в разделе нет ни одного кадра — база недоступна или
до переноса ещё не дошло. Как только в админке появился хотя бы один кадр,
подбор идёт только по ней, и удалённый менеджером кадр не возвращается из кода.

База живёт в докер-томе `promo_pgdata` и переживает перезапуск. `npm run
db:down` останавливает контейнер, данные при этом остаются.

Если `docker` просит права, значит группа ещё не подхватилась после установки:
перелогиньтесь или разово запускайте через `sg docker -c "..."`.

## Проверка мессенджеров с локальной машины

Telegram, MAX и GREEN-API стучатся к нам сами и сами же скачивают картинки
пригласительных, поэтому им нужен адрес, доступный из интернета по HTTPS с
доверенным сертификатом. Туннель Cloudflare даёт такой адрес без своего домена
и без VPN — нужен только сам `cloudflared`
([установка](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)).

```bash
npm run tunnel
```

Команда напечатает адрес вида `https://имя.trycloudflare.com`. Дальше:

1. пропишите его в `NEXT_PUBLIC_SITE_URL` в `.env` — дев-сервер подхватит
   правку сам, перезапускать не нужно;
2. зарегистрируйте вебхуки: `curl -X POST "$АДРЕС/api/invite-test/setup?key=$INVITE_TEST_SETUP_KEY"`;
3. пройдите воронку и отправьте код из мессенджера.

Адрес живёт, пока запущен `cloudflared`, и при следующем запуске будет другим —
после перезапуска шаги 1–2 нужно повторить. Постоянный адрес даёт именованный
туннель Cloudflare со своим доменом.

Пока туннель поднят, наружу открыт весь сайт вместе с `/admin`, поэтому не
оставляйте его запущенным дольше проверки. Шлюз админки на туннель
распространяется: заполните `ADMIN_GATE_*`, иначе панель будет открыта всему
интернету на всё время проверки.

## Доступ в админку

Аккаунт в панели один на автоцентр: логин общий, личных входов нет — забытый
аккаунт уволившегося менеджера не остаётся открытой дверью. Заводит и меняет
его команда:

```bash
npm run admin:reset
```

Она берёт `PAYLOAD_ADMIN_EMAIL` и `PAYLOAD_ADMIN_PASSWORD` из `.env`, создаёт
аккаунт или меняет ему пароль, снимает блокировку после неудачных входов и
**удаляет все остальные аккаунты**. Пароль не короче 12 символов
(`openssl rand -base64 24`); он лежит в `.env` сервера, поэтому вспомнить его
можно, не заглядывая в базу. Сменить общий адрес — поправить
`PAYLOAD_ADMIN_EMAIL` и запустить команду ещё раз: новый аккаунт заведётся,
прежний удалится.

До формы входа Payload посетитель не доходит: `src/middleware.ts` держит перед
`/admin` и `/payload-api` отдельный пароль (HTTP Basic), который браузер
спрашивает первым.

- `ADMIN_GATE_USER` и `ADMIN_GATE_PASSWORD` — логин и пароль шлюза. Пароль
  должен отличаться от пароля менеджера: подбирать нужно две пары, а не одну.
- **На проде без них админка не открывается вовсе** — отвечает 503 с просьбой
  их заполнить. Незакрытую панель лучше не поднять по недосмотру, чем поднять.
  Локально шлюз выключен и разработке не мешает.
- `ADMIN_ALLOWED_IPS` — необязательный список адресов через запятую. Заполнен —
  с чужого адреса `/admin` отвечает 404, и подбирать пароль шлюза не с чего.
- Пройденный шлюз запоминается кукой на 12 часов, поэтому интерфейс админки
  работает целиком, а к утру вход спрашивается заново.

Загрузки Payload (`/payload-api/*/file/*`) шлюз пропускает: по этим ссылкам
страницы воронки берут кадры и слайды, а GREEN-API скачивает картинки
пригласительных. Закрыть их — не доставить пригласительные гостю.

Сам вход в Payload тоже заперт: пять промахов подряд — и аккаунт недоступен
четверть часа (`src/collections/Users.ts`), сессия живёт 12 часов.
`robots.txt` служебные адреса не отдаёт поиску.

## Переменные окружения

Все описаны в `.env.example`. Обязательные — `DATABASE_URL` и
`PAYLOAD_SECRET`. Без `CAR_API_URL` определение авто по номеру выключено, и
воронка сразу просит заполнить марку и модель вручную. Без `NEXT_PUBLIC_YM_ID`
не подключается счётчик Яндекс.Метрики.

Переменные с префиксом `NEXT_PUBLIC_` попадают в сборку и меняются только
пересборкой: правка в `.env` без `npm run build` до браузера не доедет.

## Развёртывание на сервере

Нужны Node 20+, Postgres 16 и домен с сертификатом. Мессенджеры стучатся к нам
сами и сами скачивают картинки пригласительных, поэтому HTTP-адрес и
самоподписанный сертификат не годятся: без настоящего HTTPS пригласительные до
гостя не дойдут.

**1. База.** Managed-Postgres у хостера или свой контейнер — тогда закройте порт
5432 от внешнего мира и поменяйте пароль `promo/promo` из `docker-compose.yml`:
он годится только для локальной разработки.

**2. Код и переменные.**

```bash
git clone https://github.com/bozhedom/lexus_promo.git && cd lexus_promo
cp .env.example .env
npm ci
```

В `.env` обязательно: `DATABASE_URL`, свежий `PAYLOAD_SECRET`
(`openssl rand -hex 32`), `NEXT_PUBLIC_SITE_URL` с настоящим https-доменом,
`ADMIN_GATE_USER`/`ADMIN_GATE_PASSWORD` и `PAYLOAD_ADMIN_EMAIL`/
`PAYLOAD_ADMIN_PASSWORD`. Без пары `ADMIN_GATE_*` админка на проде не
открывается.

**3. Схема, аккаунт, сборка.**

```bash
npm run migrate
npm run admin:reset
npm run build
```

**4. Запуск.** `npm start` держит сайт на порту 3000; заворачивать его в
systemd-юнит или pm2 — чтобы поднимался после перезагрузки. Перед ним nginx:
проксирует на `127.0.0.1:3000`, отдаёт сертификат (`certbot --nginx`) и передаёт
`X-Forwarded-For` — по нему работает `ADMIN_ALLOWED_IPS`. Здесь же удобно
закрыть `/admin` вторым слоем: `allow` для адреса автоцентра, `deny all`.

**5. Вебхуки мессенджеров.** Один раз после того, как домен заработал:

```bash
curl -X POST "https://ваш-домен/api/invite-test/setup?key=$INVITE_TEST_SETUP_KEY"
```

Проверить настройку каналов — `https://ваш-домен/api/invite-test/status`.
Подробности в `src/invite-test/README.md`.

**Что беречь.** Загрузки Payload лежат в папке `media/` рядом с проектом, а не
в базе: там же и выписанные пригласительные, которые уходят гостям. Папку нужно
сохранять между выкладками и класть в бэкап вместе с дампом Postgres. Обновление
дальше — `git pull && npm ci && npm run migrate && npm run build` и перезапуск
сервиса.

## Выдача пригласительных

После ввода имени, отчества и согласия открывается модалка с двумя
приглашениями: «Диагностика» и «В честь знакомства». Любое приглашение
раскрывается на весь экран. После просмотра приглашений номер телефона вводится
в отдельном окне и подтверждается кодом из СМС.
На экране «Команда автомобиля» приглашения выдаются только через MAX или
Telegram — скачивания файла в интерфейсе нет. Настройка мессенджеров — в
`src/invite-test/README.md`, переменные `INVITE_TEST_*` в `.env.example`.

Картинки сертификатов рисует сервер (`ImageResponse`, 1080×1620): имя гостя,
его марка и настоящий госномер прямо на кадре автомобиля. Формат 2:3 выбран
под мессенджеры — WhatsApp и Telegram показывают его в переписке целиком.

В правом нижнем углу печатается номер выдачи: золотая буква вида и шесть цифр
(`A 000001` — диагностика, `B 000001` — замена масла). Отсчёт у каждого вида
свой и начинается с единицы; номер считается от последнего выписанного в
разделе «Сертификаты», поэтому очищенный раздел нумеруется заново. Номер лежит
в поле «Номер выдачи» и задним числом не меняется.

## Как устроен код

- `src/app/(frontend)` — страницы воронки, `src/app/(payload)` — админка
- `src/views` — экраны, `src/widgets` — крупные блоки, `src/shared` — общее
- `src/collections` — коллекции Payload (заявки, сертификаты, события)
- `src/lib` — серверная логика: валидация, внешний API, рейт-лимит
- `src/migrations` — миграции базы

### Адаптивность

Экраны нарисованы в кадре 360×800, поэтому размеры не константы, а функции из
`src/shared/config/_fluid.scss`:

- `f.vh($lo, $hi)` — линейная привязка к высоте: `$lo` на 568px, `$hi` на 800px;
- `f.frame($px)` — величина кадра, ужатая сразу по ширине и высоте.

Правило простое: первый экран и формы обязаны помещаться целиком на самом
низком телефоне (320×568), длинные экраны (ручной ввод авто, галерея) могут
прокручиваться. Проверяется прогоном `npm run e2e` в нужном размере: он пишет
рядом с каждым шагом, влезает экран или нет.

### Ввод номера и кода

Госномер и код из СМС набираются собственной экранной клавиатурой
(`src/shared/ui/Keypad`): системную нельзя сузить до двенадцати разрешённых
букв, а на фокусе Safari увеличивает страницу. Оба поля хранят значение
позициями, поэтому каретку можно поставить в любую ячейку тапом, а «Стереть»
убирает ровно один символ.
