# Разделы админки

## Тексты сообщений

Держит формулировки, которые уходят в мессенджеры: сообщение, приходящее гостю
вместе с пригласительными, текст, который гость отправляет менеджеру, и текст
записи на сервис. Подстановки пишутся в фигурных скобках — `{name}`, `{car}`,
`{plate}`, `{amount}`, `{code}`, `{services}`; строка, где все подстановки
оказались пустыми, из сообщения выпадает целиком.

Если в тексте записи нет `{services}`, отмеченные работы дописываются отдельной
строкой в конце — так их не потеряет уже настроенная формулировка. Правка
применяется к следующей выдаче, перезапускать приложение не нужно, а пустое
поле возвращает текст по умолчанию из `src/invite-test/config/certificates.ts`.

**Убирать `{code}` из текста гостя нельзя:** по нему сервер понимает, кому
отправлять пригласительные.

## Слайды автоцентра

Фотографии под формой и их вертикальные версии для мобильного полноэкранного
просмотра. До первого заполнения раздела подставляются встроенные слайды из
`src/widgets/news-slider/slides.ts`.

## Правила сумм

Задаёт сумму сертификата для списков моделей. При отсутствии подходящего правила
используется `CERT_AMOUNT`, затем значение 1500 ₽.

## Марки и модели

Каталог ручного ввода. По умолчанию доступны только Toyota и Lexus;
опубликованные дополнительные марки и модели автоматически появляются в форме.

## Фото автомобилей

Кадры, на которых печатается пригласительный, и единственный источник этих
кадров. Весь каталог живёт здесь: тридцать один кадр приезжает миграцией
`20260813_190000_car_photos_seed`, дальше фотография меняется загрузкой файла,
рамка знака — процентами, а новая модель заводится кнопкой. Где база поднята
схемой разработки и до миграций дело не доходит, раздел заполняет
`npm run seed:car-photos`; повторный запуск непустой раздел не трогает.

Кадр подбирается по марке, модели и году: чем точнее совпадение, тем выше
приоритет. Пустая модель означает «любая модель этой марки», пустые годы —
«любой год». Загружать нужно вертикальный кадр не меньше 1080×1920: под
госномер на нём должно остаться пустое место, а куда именно печатать номер,
задают проценты в блоке «Рамка госномера».

Поколения одной модели разводятся годом выпуска: у нового кадра годов нет,
поэтому он же достаётся автомобилю с неизвестным годом, а старому проставлен
верхний год. В каталоге модель называется без поколения («RAV4», «LX»),
и по-другому их не различить.

Те же кадры лежат в `public/images/cert/cars`, а список — в
`src/shared/config/car-photos.ts`. Это страховка: встроенный список
подставляется, только когда в разделе нет ни одного кадра — база недоступна или
до переноса ещё не дошло. Как только в админке появился хотя бы один кадр,
подбор идёт только по ней, и удалённый менеджером кадр не возвращается из кода.

## Ветка записи в сервис

На записи пригласительные не выписываются. Карточка автомобиля показывается
всегда — и когда его определили по номеру, и когда гость вписал марку руками, —
а вместо подарков на ней три работы с чекбоксами (список лежит в
`src/shared/config/services.ts`). «Это мой автомобиль» уводит на
`/booking/appointment`, где сразу стоят три кнопки мессенджеров: гость выбирает
любую и уходит в чат с готовым текстом про свой автомобиль и отмеченные работы.

Выданные пригласительные ветку записи не перехватывают: гость, которому их уже
выписали, проходит определение автомобиля так же, как все.
